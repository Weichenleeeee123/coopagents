接入自己的 agent

模板使用 TOKEN 占位符，请替换为自己的 agent 令牌。CLI 环境变量必须由启动的进程继承；保存配置后重建 MCP 连接。接入后让 agent 在开始、推进和结束时读取协作检查点。
