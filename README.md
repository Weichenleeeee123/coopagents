Your agents. One team. / 各自开工，始终同频。

帮助各自使用 Claude Code 和 Codex 的队友共享分工、交换技术信息并跟踪依赖。原有入口的本地消息链已通过，共享服务已有身份与原子任务认领的领域实现；网页与跨电脑传输尚未实现。

所有持续维护的设计、计划、运行说明和验证记录统一存放在 [docs/](docs/README.md)，随代码分阶段提交。

共享服务领域源码位于 `src/crewmesh/`，测试位于 `tests/`，具体阶段见 [后续路线](docs/roadmap.md)。接入实验源码位于 `work/crewmesh-integration-lab/`，运行步骤见 [接入实验说明](docs/integration-lab.md)。虚拟环境、机器配置和原始测试证据保留在本地，不提交 Git。历史交付包保留在 `outputs/`。
