## 身份阶段

实现 `IdentityStore`：创建房间、增加成员、解析身份、查询本房间成员与撤销 agent 凭据。网页和 agent 使用独立随机令牌，数据库仅保存 SHA-256 摘要；身份和房间由数据库记录解析，不接受自报作者标签。写操作在同一 SQLite 事务内验证身份并修改数据。

13 项行为测试覆盖权限、跨房间隐藏、凭据分离与撤销、名称校验、持久化、数据库无明文凭据、失败回滚及连接关闭。规格审查与代码质量审查均通过；主代理独立运行测试，退出码为 0。额外验证了无效 Unicode 凭据统一返回 AccessDenied，不回显输入。

此阶段的网页令牌代表持有者权限，尚无浏览器登录、邀请兑换或令牌轮换接口。令牌创建结果是内部领域接口返回值，不是公共邀请链接。

Git 阶段提交：计划 `222f398`；身份实现 `3324da5`。

## 任务认领阶段

实现 `TaskStore`：网页凭据创建任务，两种凭据查看本房间任务，agent 凭据认领任务。相同意图键与相同内容返回原任务，不同内容产生冲突；同成员重复认领保持原负责人和时间。已被别人认领时返回本房间负责人，跨房间和不存在的任务统一隐藏。

认领在 `BEGIN IMMEDIATE` 事务中检查凭据、查询房间范围并更新归属；数据库的复合外键约束负责人属于同一房间。四个不同成员通过独立连接同步竞争同一任务，验证得到一个成功与三个冲突，最终只有一个负责人。

新增 12 项任务行为测试，与身份阶段共 25 项，主代理独立执行全部通过，退出码为 0；规格审查与集成代码质量审查均通过。覆盖输入边界、精确重复、冲突、权限、撤销后的拒绝、重开后的持久化、跨房间外键拒绝和失败回滚。

`claimed` 只表示任务归属，不表示 agent 正在开发。此层避免同一任务被重复认领，尚不识别不同任务描述之间的语义重复，也不锁定本地文件或分支；会话、范围提示和实际工作状态属于 P2.3。

Git 阶段提交：任务认领实现 `ce4294f`。
