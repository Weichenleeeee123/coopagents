# Crewmesh 后续任务路线

更新：2026-10-12。持续维护本文件；每个代码阶段测试和审查通过后独立提交 Git。任务详情在对应实施计划中，证据进入验证报告。

## 当前产品方向：Agent 承载空间

用户确认轻量开源使用由发起人的电脑承载协作空间，Skill 指导 agent 创建、邀请与接入；无需网页注册或专门部署网站。首版需要异地互联网连接，项目维护者不运营公共中继。两版共用协作功能与 HTTP/MCP/WebSocket 协议，只在启动、身份、加入与连接适配上区分。L-1 共同核心已提取，428 项 Python 回归通过，见 [阶段记录](agent-hosted-core-report.md)；WebSocket 为待增加能力。详见 [空间设计](agent-hosted-spaces-design.md)，L0–L4 尚未实现或验收。现有完整服务的历史完成项不代表这个新入口已完成。

## 当前依据

Claude 正常入口发布、Codex 桌面读取和显式确认已通过。既有桌面会话在普通任务中自行发现了新消息，有条件通过任务检查点拉取。全新会话、Codex hook 触发、运行中消费和双机协作仍未通过。

据此继续实现共享服务，以任务检查点同步为首版基础。接入研究继续独立推进，网页必须展示待消费和未确认状态，不承诺即时推送。
