# 轻量接入产品设计

## 已批准的体验

项目管理员复制邀请链接，队友打开网页完成登录/注册并明确加入指定项目。加入后网页直接提供 Crewmesh 接入 Skill 的下载与无秘密引导文本；用户交给已有 Claude Code 或 Codex，由 agent 配置原生 MCP。没有独立 Crewmesh 本地客户端、安装器或常驻进程。

## 邀请

延续单次 24 小时有效邀请，链接 fragment 不进入 HTTP 请求；打开页面立即清除 fragment，预览不消费。注册和已有账号接受后进入邀请指定项目（多项目让用户选择）。已有团队成员接受新项目邀请不会替换原团队角色或再次占用成员额度。邀请失效与没有可访问项目均明确提示。OAuth 跳转如不能安全保留邀请，要明确说明原链接重开，不隐式吞掉邀请。

## Skill 身份连接（用户进一步批准的简化方案）

公开 Skill 不含成员凭据。用户在已登录项目明确点击“接入 agent”，服务验证当前项目成员资格，发行新的个人 agent 凭据（不轮换、不让已有连接失效），网页展示包含 Skill URL、服务、项目、工具和凭据的私有接入指令。用户复制给自己的 agent，一次完成接入。不增加设备授权或轮询。

该按钮仅发行本人当前项目的 agent 凭据，不能信任前端自报 member_id；要求原有网页认证和 CSRF/Origin 防护。默认不在快照中返回凭据；指令只在弹窗内短暂显示，关闭、退出、切换项目清空，迟到响应不能恢复指令，不写浏览器持久存储或 URL。沿用个人 agent 凭据有效期与撤销规则。

agent 将凭据写入原生工具私有配置，不重复输出、不提交 Git、不写 URL。先检查已有配置并合并独立项目配置，不覆盖其他 MCP、权限、信任或认证设置。需重启时给具体指引，不能把 HTTP 成功声称为当前会话已加载 MCP。

## 验证与边界

真实身份读取 + checkpoint / 诊断读回分别记录。网页区分凭据授权、服务调用和原生自动同步证据。Skill 接入不自动安装旧 Python hook 工具，不承诺闲置 agent 唤醒或模型自动消费上下文。运行节点的团队读取通过 Skill 指令与现有 MCP 实现，原生自动触发仍独立验收。

测试覆盖邀请预览/过期/单用、已有账号/注册/已有团队成员、错误范围、当前管理员权限，以及接入凭据权限/CSRF/不轮换旧连接/项目切换与关闭后的迟到响应。原始证据保存在忽略的 .local/。
