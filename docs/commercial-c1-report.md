# C1 账号与工作区候选版验收

日期：2026-10-11。候选版：`0.3.0rc1`。用户已批准完整开源 + 未来官方托管订阅，C1 设计和实施均已批准。C1 代码、独立审查、本机测试、打包安装及最终 CI 的扩展 TLS 验收已通过。保留 v0.2.0 发行资产，不覆盖历史发行。

## 已实现范围

- 本地 scrypt 密码账号、规范化用户名、首次密钥初始化、邀请注册、七天可撤销账号会话。
- 独立团队 / 项目授权、owner/admin/member 角色、最后 owner 保护、24 小时单次邀请、明确项目范围、成员和邀请撤销。
- Cookie 账号认证与项目 / MCP bearer 分离，Origin / CSRF 校验，项目选择凭据绑定账号会话；切换清除原项目及异步过期响应。
- 历史项目通过 owner 网页凭据认领，附加数据库迁移保留数据和旧协作者凭据，不按姓名自动绑定账号。
- 本人改密、团队管理员按角色重置、文件系统授权的离线恢复；缺失数据库不创建、未知或 GitHub-only 身份拒绝、事务撤销会话与派生网页访问。CLI 双重隐藏输入，无法隐藏输入时拒绝运行。
- 显式配置的 cloud GitHub OAuth 数字 ID 绑定、一用 state / PKCE / 浏览器绑定、固定提供方地址；未配置自托管完全本地运行。
- 自托管 Compose、HTTPS Cookie / 代理说明、一致备份与新路径恢复，CI 包含账号 UI 语法和回归检查。无需付款或官方许可，没有虚构账单界面。
