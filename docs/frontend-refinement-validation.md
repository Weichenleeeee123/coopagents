# 轻量黑白前端交付与验收

日期：2026-10-30。用户确认 A「轻量黑白工作台」，设计见 [设计稿](superpowers/specs/2026-10-30-frontend-refinement-design.md)，实施见 [计划](superpowers/plans/2026-10-30-frontend-refinement.md)。

## 交付

- 延续黑白品牌，使用浅灰内容背景、细边线、6px 控件与任务卡片圆角。移除硬偏移阴影，统一字号、字距、表单、状态、焦点和留白。
- 登录改为品牌与表单的单列入口。账号中心、项目页面、任务抽屉、仓库、账单和本机只读看板共用视觉基础；设置和证据使用无框章节，重复条目使用轻量记录。
- 项目侧栏收至 232px。宽屏看板五阶段并排，较窄桌面保留三列，手机看板内部横滑。手机导航和筛选压缩，长项目名、成员名与路径可以换行。
- 团队现场优先展示成员与 agent、共享上下文、交付关联；成员进展、范围交叠和完整支持矩阵按需展开。活动列表限制高度，避免持续拉长页面。
- 共享上下文保留搜索、任务、成员三项常用筛选，其他条件收入更多筛选；草稿、查询结果和展开状态在刷新时保留，切换项目与清除会话时隔离。
- 每个 agent 展示自己的 Harness、版本、平台、分支、任务与登记时间；连接与能力证据可展开。成员、会话和工具各自隔离展开状态，登记仍不等同在线或模型处理。
- 交付状态增加中文表达，保留来源、确认状态、时间与权限。刷新按钮使用带可访问名称和提示的 Lucide 图标，图标授权随 HTML 分发。

接口、数据库、任务状态机和 Harness 支持判定均未变更；本轮只调整静态页面、共同渲染及对应界面回归。

## 真实浏览器

使用 Playwright CLI 和真实本机 Starlette/SQLite 服务。种子包含两个合成账号、两个团队、两个项目、七项任务、三条 Harness 会话、一项有回复请求、一项生效约定、一个待确认交付建议和一个共享资产。未模拟网页接口。

- 登录、账号四视图、项目五视图和只读看板在 1440、1280、768、390、320px 下均无文档横向溢出；看板在自身容器滚动。
- 项目与只读任务详情打开、Escape、焦点返回通过；手机抽屉无溢出。
- 任务搜索无匹配、清除筛选、共享上下文查询、草稿保留、高级筛选与能力证据刷新保持通过。
- 接入弹窗关闭清空配置、断线保留七项任务、恢复连接、空团队与登录错误状态通过。
- 只读看板展示共同三项能力，不显示交付确认操作。
- 抽查九组计算样式的文本对比度为 4.67:1–16.10:1，均达到 4.5:1；减少动态效果设置生效。
- 390/320px 注入长项目名、长成员名、中文长标题和长路径，文字可换行；320px 品牌右边界 154px，项目名左边界 166px，互不重叠。
- 已观察桌面/手机看板、团队现场、账号设置、登录、长文字等截图。主流程未捕获页面脚本异常；断线和错误登录测试产生预期请求错误，不作为产品故障。

首轮自动截图曾在视图恢复与登录动画完成前截取，另有对比度定位命中隐藏表单的脚本问题。已修正等待条件和定位后重新验证，最终截图不使用这些中间状态。
