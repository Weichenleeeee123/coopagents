- 全站浅灰背景、白色内容、近黑导航与主操作；硬边框、直角控件、大数字与灰阶状态标签统一到登录、团队中心四视图、项目五视图、任务/凭据弹窗、Git 接入与 Billing。品牌图标使用 CSS 灰阶，不改资产文件。
- 桌面侧栏约 265px；任务保留五阶段分类，按三列分组。手机只在看板内部横滑，摘要改为两列。
- 顶部摘要来自完整 snapshot：协作任务、团队成员、待解决请求、已合并任务。筛选仅影响卡片；创建任务与解决请求更新摘要。成员数不冒充在线 agent 数，合并不等于验收，详情仍分别标注证据来源。

## 真实浏览器验收

Playwright 连接独立本机 Starlette/SQLite 服务，种子和操作均经实际 HTTP API，未 mock。两个合成账号、两个团队，初始两项目/七任务；浏览器创建后为三项目/八任务，并实际解决请求、批准约定。

- 看板与登录在 1440、1280、768、390、320px 无文档横向溢出；团队中心四视图检查 1280、768、390、320px；项目其他四视图检查桌面、390、320px；任务详情检查 390、320px。
- 项目/任务创建、收起表单、搜索与负责人组合筛选、无匹配提示、清除筛选、详情 Escape 与焦点返回通过。
- 摘要初始 `07/02/01/01`；创建任务与解决请求后 `08/02/00/01`，筛选后仍为项目总数。
- 邀请项目权限默认未勾选；凭据关闭即清空。团队切换、同团队刷新保留视图和账单返回的权威等待状态通过。实际普通成员无项目创建、团队管理和付款操作。
- 断线保留任务，重连清除通知；减少动态效果时无入场动画。
- 从实际计算样式检查正文、卡片描述/时间/范围、主按钮、选中导航、品牌、摘要与看板说明共九组文字对比度，最低 4.67:1，均高于 4.5:1。
- 最终截图重新加载最终 CSS 并等待动画；卡片白底、近黑边框、0px 圆角，顶栏未误继承负责人分隔线。

截图脚本曾把账单返回或保留的其他视图当作看板等待。改为显式进入项目并选择任务视图后，最终截图脚本通过；这属于测试流程修正，未修改产品导航。控制台只有预期的登录前 `/account/session` 401、主动断线的 snapshot 网络错误和已有表单 autocomplete 建议，未观察到未捕获脚本异常。
