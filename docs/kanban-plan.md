# 看板与品牌升级

用户已选择自动分列、点击详情，保持网页和 agent 的现有权限。参考截图采用任务列与卡片，不复制截图中的文章内容。

## 设计

默认进入任务看板。五列依次为待认领、推进中、遇到阻塞、待验收、已合并。未认领归第一列；claimed / working 归推进中；blocked 归阻塞；local_done / pushed / pr_open 归待验收；merged 归已合并。列标题标明待验收仅来自 agent 自述，不代表新增人工完成审批。

卡片展示任务编号、标题、负责人、范围、最新进展、技术请求计数和更新时间。搜索标题/范围/进展，按负责人过滤，两种筛选可组合。点击卡片打开原生 dialog 详情，保留请求、公共约定跳转。刷新时保留筛选、详情和表单；401 清除详情及会话。使用 textContent 渲染用户文本，不以拖拽变更状态。

品牌使用石墨侧栏、白灰面板、青绿强调色，生成一个交织 C 图标。图标存 src/static/icon.png，固定公开静态路径、包资源、CSP不变。README 采用图标、短定位、真实看板截图、使用流程、跨平台启动和能力边界。
